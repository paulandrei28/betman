# Betman

Betman is a static, installable archive for daily reports generated by `game_analyst`.

## Report views

Each report can be explored in three ways:

- **Top picks** shows the 20 highest-ranked predictions after filters are applied, grouped by match.
- **By match** preserves the full match grouping.
- **By market** groups markets into broader categories while keeping each match's evidence expandable.

The top picks and market views are derived in the browser from the report JSON. Existing report files do not need a new format.

## Language

Use the flag in the upper-right corner to switch between English and Romanian. The selected language is saved in the browser. Romanian includes localized betting terminology for markets and evidence labels.

## Local development

Start a local server from the project directory:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

There is no build step. The deployed files are the app itself.

Reports are stored in `data/reports/`, and `data/reports.json` lists the available reports. Generated files should not be edited by hand.

## Rebuilding reports

After a report changes, rerun the `game_analyst` producer so it rewrites `data/reports.json`. If the producer is unavailable, remove the deleted report's entry from `data/reports.json` as a recovery step. The matching file under `data/reports/` must also exist for its calendar entry to open successfully.

## Deployment and caching

GitHub Pages deploys the site after updated files are committed and pushed.

Betman is installable and uses a service worker. If an older report still appears, refresh the page after clearing the site's cached data.
