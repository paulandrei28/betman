# Betman

Static, installable archive for daily reports generated by `game_analyst`.

For local preview, run `python -m http.server 8000` in this directory and open `http://localhost:8000`. The producer writes `data/reports.json` and formatted daily JSON files under `data/reports/`. Generated files should not be edited by hand.

## Rebuilding after a report change

There is no build step. This is a static site, so the deployed files are the app itself. To remove a deleted report, rerun the `game_analyst` producer so it rewrites `data/reports.json`; if the producer is unavailable, remove the deleted report's entry from `data/reports.json` as a recovery step. The matching file under `data/reports/` must also exist for a calendar entry to open successfully.

After committing and pushing the updated files, GitHub Pages deploys the site. For a local check, run `python -m http.server 8000` and open `http://localhost:8000`. If an older report still appears, refresh the page after clearing the site's cached data because the app is installable and uses a service worker.

The `data/analysis` folder is not used by this app and is not tracked in Git. It is likely leftover output from an older analyzer layout; current reports belong in `data/reports/`, with their paths listed in `data/reports.json`. It can be deleted locally.
